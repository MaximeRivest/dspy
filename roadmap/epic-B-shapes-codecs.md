# Epic B — shapes + codecs

**Goal:** factor value encoding out of the formats into **codecs** — shape-generic
render/parse pairs deciding the wire syntax of a value — per the spec's
§Adapter-semantics (`roadmap/IR-program-spec.md`), and audit/repair arbitrary
Python type-hint support in signatures ("shape liberation"). Engine-private;
zero public-surface change; golden corpus byte-identical at every commit.

## PR stack

1. **B-1 corpus: pin value-encoding behavior** (`test(adapters):`, corpus-only,
   zero `dspy/` changes). New `shapes--` request family across all five
   adapters: list-of-models, dict field, optional/null, unicode, enum. New
   parse cases (chat + json) for enum/optional/unicode/list-of-models coercion.
   *Done when:* fixtures generated by the protocol script in a dedicated
   commit; `test_fixture_files_match_registry` green.
2. **B-2 codec seam** (`refactor(adapters):`). `_engine/codecs.py`:
   `ValueCodec` with `render_value(value, field_info) -> str` /
   `parse_value(text, annotation) -> Any`; `TextPythonishCodec` wrapping
   today's `format_field_value`/`parse_value` pair; `PydanticJSONCodec`
   (BAML's `model_dump_json(indent=2, by_alias=True)` input preference).
   `Format` gains `input_codec`/`output_codec` bindings (directional,
   independent); chat/xml/json route per-value encoding through the bindings;
   BAML decomposes to JSONFormat + `input_codec = PydanticJSONCodec`.
   *Done when:* corpus byte-identical with ZERO regeneration; codecs own the
   value-syntax literals; formats keep structure literals; `render.py` diff
   is zero.
3. **B-3 shape liberation** (`fix(adapters):`). Loud typed refusal for hints
   with no JSON-schema meaning (`Callable`, `type`, …) naming the field and
   pointing at tools — replacing today's raw
   `PydanticInvalidForJsonSchema` with no field context. No silent-degrade
   behavior changes (deferred: they alter bytes).
   *Done when:* refusal is typed + tested; corpus untouched.
4. **B-4 codec tests** (`test(adapters):`). Round-trip property coverage
   (`parse(render(x)) == x`) over representative + adversarial values
   (nesting, unicode, empty collections, None), non-round-trip quirks pinned
   as documented facts.

## Gates (every PR)

- `tests/adapters/test_golden_parity.py` green with zero fixture drift
  (B-1 adds fixtures in its own corpus commit first).
- `dspy/__init__.py` + `dspy/adapters/__init__.py` untouched.
- Full `dspy-ci` matrix green.

## Non-goals (deferred)

- The component-2 `shape`/`semantic_role` split and any public `role=` API
  (Epic C).
- Schema-prose as a first-class *schema codec* (BAML's `_render_type_str`
  stays a format literal until the codec pool exists).
- Public codec registration/selection API; per-field codec overrides;
  codec optimization plumbing (spec §e2 — needs the pool).
- Silent-degrade shape fixes that change rendered bytes (`str()` fallback in
  `serialize_for_json` etc.) — candidates for a later corpus-gated change.
